# 光学镜片加工全流程

## 1. 总体流程

光学镜片制造完整流程：

```text
光学玻璃原料
↓
玻璃材料检验
↓
下料切割
↓
滚圆（外圆加工）
↓
粗磨
↓
精磨
↓
抛光
↓
光学检测
↓
定心加工
↓
清洗
↓
镀膜
↓
镀膜检测
↓
镜片入库
↓
镜头装配
↓
MTF测试
↓
成品
```

---

# 2. 光学玻璃材料准备

## 2.1 光学玻璃选择

### 目的

根据光学设计要求选择合适玻璃材料。

主要参数：

| 参数     | 说明       |
| ------ | -------- |
| 折射率 nd | 决定光线折射能力 |
| 阿贝数 Vd | 决定色散能力   |
| 透过率    | 影响成像亮度   |
| 内部气泡   | 影响成像质量   |
| 应力     | 影响双折射    |

常见玻璃：

- 冕牌玻璃（K类）
- 火石玻璃（F类）
- ED低色散玻璃
- 石英玻璃


## 设备

通常由玻璃供应商完成：

- 折射率测试仪
- 光谱仪
- 应力测试仪


## 注意事项

工业镜头需要关注：

- 批次一致性
- 折射率偏差
- 内部缺陷

影响：

- 焦距变化
- 色差
- MTF下降

---

# 3. 下料切割（Cutting）

## 目的

将大块光学玻璃切割成接近尺寸的毛坯。


例如：

设计镜片：

```
φ20mm
```

毛坯：

```
φ23mm
```

预留加工余量。


## 设备

- 金刚石切割机
- 水冷切割设备


## 注意事项

重点控制：

- 崩边
- 裂纹
- 热应力

切割后通常需要：

- 清洗
- 退火处理

---

# 4. 滚圆（Centering）

## 目的

将不规则毛坯加工成圆形。

作用：

建立机械基准。


加工过程：

```text
不规则毛坯

↓

圆柱形镜片毛坯
```


## 设备

- 外圆磨床
- 滚圆机


## 控制指标

- 外径尺寸
- 圆度
- 同轴度


## 注意事项

滚圆质量影响后续：

- 定心
- 装配精度

---

# 5. 粗磨（Rough Grinding）

## 目的

快速加工镜片曲率。


例如：

设计：

```
R=50mm
```

粗磨：

```
R≈50.2mm
```


## 加工方式

采用金刚石砂轮：

```text
砂轮

 ↓

镜片
```


## 设备

- 球面研磨机
- CNC光学加工机


## 加工内容

控制：

- 曲率半径
- 中心厚度
- 材料去除量


## 注意事项

粗磨主要追求：

- 加工效率

不追求：

- 表面质量


容易产生：

- 亚表面损伤
- 微裂纹

---

# 6. 精磨（Fine Grinding）

## 目的

进一步提高曲率精度，降低表面粗糙度。


## 工艺

采用更细磨料：

```text
粗磨：

#200

↓

精磨：

#800
#1200
```


## 设备

- 精磨机
- 球面研磨机


## 控制指标

- 曲率误差
- 表面粗糙度
- 中心厚度


## 注意事项

精磨质量直接影响：

- 抛光效率
- 最终面形

---

# 7. 光学抛光（Polishing）

## 目的

获得透明、高质量光学表面。


去除：

- 磨砂层
- 微裂纹
- 亚表面损伤


## 工艺材料

主要：

- 抛光盘
- 氧化铈（CeO₂）抛光粉


## 设备

- 单面抛光机
- 双面抛光机
- 光学抛光机


## 关键指标

### 表面粗糙度

普通机械：

几十nm

高质量光学：

<1nm


### 面形精度

例如：

```
λ/4
λ/10
```


## 注意事项

抛光决定：

- 成像清晰度
- MTF性能


常见问题：

- 面形变形
- 橘皮
- 麻点

---

# 8. 光学检测

## 目的

确认镜片是否达到设计要求。


---

## 8.1 曲率检测

检测：

- 曲率半径R


设备：

- 曲率半径仪


---

## 8.2 面形检测

检测：

- 球面误差
- 非球面误差


设备：

- 激光干涉仪


指标：

```
λ/4
λ/10
```


---

## 8.3 表面质量检测

检测：

- 划痕
- 麻点
- 污染


常见标准：

```
40/20
```

表示：

划痕等级 / 麻点等级。


---

# 9. 光学定心（Centering）

## 目的

使：

```
机械中心

=

光学中心
```


## 原理

镜片两个球面的曲率中心可能不重合：

加工前：

```text
C1 ●

      \
       \
        ● C2
```


定心后：

```text
C1
|
|
C2
```


---

## 设备

- 光学定心车
- 自准直定心仪


---

## 加工内容

主要加工：

- 外圆
- 倒角


---

## 关键指标

偏心量：

普通工业镜头：

```
≤3μm
```


高精度镜头：

```
≤1μm
```


---

## 注意事项

定心影响：

- 光轴一致性
- MTF
- 边缘分辨率

工业镜头中属于关键工序。

---

# 10. 清洗

## 目的

## 设备

# 11. 光学镀膜（Coating）

## 目的

降低反射，提高透过率。


未镀膜玻璃：

空气-玻璃界面：

约4%反射。


镀膜后：

可降低至：

<0.5%


---

## 常见膜层

### 增透膜 AR

Anti Reflection


### 防水膜

Hydrophobic coating


### 红外膜

IR coating


---

## 设备

- 真空镀膜机
- 离子辅助镀膜设备


---

## 常见材料

- SiO₂
- TiO₂
- MgF₂


---

## 注意事项

控制：

- 膜厚
- 均匀性
- 附着力

---

# 工业FA镜头制造重点

对于：

- 机器视觉镜头
- 6片镜组
- 0.5倍倍率
- 小批量生产

重点关注：

## 第一优先级

1. 定心精度

决定：

- 光轴一致性
- MTF


2. 镀膜一致性

决定：

- 透过率
- 对比度


3. MTF一致性

决定：

- 批量产品性能稳定性


---

## 第二优先级

4. 曲率误差

5. 中心厚度

6. 镜片间距


---

# 常见批量问题

```text
光学设计MTF很好

↓

单片镜片加工合格

↓

实际镜头性能下降
```


常见原因：

- 镜片偏心累积
- 装配污染
- 间隔误差
- 镀膜批次差异
- 温漂


---

# 总结

光学镜片制造中：

- 粗磨决定曲率
- 精磨提高精度
- 抛光决定表面质量
- 定心决定光轴一致性
- 镀膜决定透过性能
- MTF决定最终成像表现

对于工业镜头，小批量制造最大的挑战不是“加工出来”，而是：

**保证每一颗镜头性能一致。**
