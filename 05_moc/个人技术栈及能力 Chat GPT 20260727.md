# 八、判断一项新技术该不该学

以后遇到一个新技术，可以问四个问题：

1. 它是否直接服务于当前项目？
2. 它是否强化我的视觉与系统优势？
3. 三个月内能否形成可展示成果？
4. 学完后会不会长期使用？

四个问题中至少有三个答案是“是”，才值得投入。

例如：

- CAN：应该学，直接服务平衡车和工业设备；
- PCB：应该学，可以让原型产品化；
- FPGA：暂缓，除非当前线扫项目必须使用；
- ROS2：暂缓，底层运动闭环完成后再使用；
- 强化学习：不学，与当前路线关系弱；
- 大模型开发：不学，把它作为工具使用。
